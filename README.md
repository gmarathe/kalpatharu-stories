# ಕಲ್ಪತರು ಕಥೆಗಳು — stories.kalpatharu.org

Senja ಬದಲಿ ವ್ಯವಸ್ಥೆ.

- `index.html` — ಕಥೆಗಳ ಗೋಡೆ (Google Sheet ನಲ್ಲಿ Approved ಆದವು ಮಾತ್ರ)
- `r/finisher`, `r/hof`, `r/superhealer`, `r/torchbearer` — ವಿಡಿಯೋ ಫಾರ್ಮ್‌ಗಳು
- `forms.js` — ಫಾರ್ಮ್‌ಗಳ ಪಠ್ಯ ಮತ್ತು ವಿಡಿಯೋ ಮಾರ್ಗದರ್ಶಿ (ಪಠ್ಯ ಬದಲಿಸಲು ಇದನ್ನು ತಿದ್ದಿ)
- `config.js` — Apps Script ವೆಬ್ ಆ್ಯಪ್ ವಿಳಾಸ
- `apps-script/` — Google Apps Script ಕೋಡ್ (Drive ಅಪ್‌ಲೋಡ್, Sheet, ಇಮೇಲ್, ಫೀಡ್, YouTube ಬ್ಯಾಕಪ್)
- `data/senja-seed.json` — Senja ಇಂದ ತಂದ 414 ಕಥೆಗಳು (ಒಮ್ಮೆ ಆಮದು)
